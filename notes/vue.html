Vue2 + Vue3 全知识点笔记 ​

一、Vue 基础核心 ​

1. 框架基础 ​

  • 定义：Vue 是渐进式 JavaScript 框架，核心是“数据驱动 DOM”，无需手动操作 DOM，专注于视图层。
  • 版本核心差异：
    维度Vue2Vue3
    核心 API选项式 API（Options API）选项式 API + 组合式 API（Composition API）
    性能基于 Object.defineProperty 响应式，存在部分性能瓶颈基于 Proxy 响应式，性能提升 1.5 倍，支持深层响应式
    体积完整版约 20KB按需打包，体积更小
    TypeScript 支持需额外配置原生支持
    生态成熟（Vuex3、vue-router3）升级（Pinia、vue-router4）
  • 学习资源：
    • Vue2 官方文档：https://v2.cn.vuejs.org/
    • Vue3 官方文档：https://cn.vuejs.org/
    • 包管理：npm/yarn，用于安装依赖

2. 开发环境与工具 ​

（1）VSCode 必备插件 ​

  • Vetur：Vue2 语法高亮、智能提示、格式化
  • Vue Language Features (Volar)：Vue3 专属，支持 TypeScript 和组合式 API
  • Path Intellisense：文件路径自动补全
  • Live Server：本地实时预览页面
  • ESLint：代码规范检查
  • Prettier：代码格式化

4. 核心语法与指令（全覆盖） ​

（1）模板渲染（3 种方式） ​

  • Mustache 插值：渲染变量/简单表达式，不覆盖标签内容
    html
    <div>{{ name }} - {{ age > 18 ? '成年' : '未成年' }}</div>
    1
  • v-text：完全覆盖标签内容，优先级高于插值
    html
    <div v-text="message"></div> <!-- 等价于 <div>{{ message }}</div> -->
    1
  • v-html：渲染 HTML 内容（注意 XSS 风险）
    html
    <div v-html="richText"></div> <!-- richText: '<span style="color:red">红色文本</span>' -->
    1

（2）事件绑定（v-on/@） ​

  • 基础用法：
    html
    <!-- 无参数 -->
<button @click="handleClick">点击</button>
<!-- 带参数 -->
<button @click="handleAdd(5, $event)">加 5</button> <!-- $event 为原生事件对象 -->
    1
    2
    3
    4
  • 事件修饰符（完整 10 种）：
    修饰符作用示例
    .stop阻止事件冒泡@click.stop="handleClick"
    .prevent阻止默认行为（如表单提交、a 跳转）@submit.prevent="handleSubmit"
    .capture事件捕获模式（外层先触发）@click.capture="handleClick"
    .self仅自身触发（子元素不触发）@click.self="handleClick"
    .once事件仅触发一次@click.once="handleClick"
    .passive提升滚动性能（不阻止默认滚动）@scroll.passive="handleScroll"
    .enter回车键触发@keyup.enter="handleEnter"
    .tabTab 键触发@keyup.tab="handleTab"
    .delete删除/退格键触发@keyup.delete="handleDelete"
    .ctrl/.alt/.shift系统键组合触发@click.ctrl="handleCtrlClick"
  • 修饰符串联：
    html
    <button @click.stop.prevent="handleClick">阻止冒泡+默认行为</button>

（6）v-model 双向绑定（全版本差异） ​

  • Vue2：

    • 基础用法：
      html
      <input v-model="username" placeholder="输入用户名">
      1
    • 本质：:value + @input
      html
      <input :value="username" @input="username = $event.target.value">
      1
    • 修饰符：.lazy（失焦更新）、.number（转为数字）、.trim（去空格）
      html
      <input v-model.lazy.number.trim="age" type="number">
      1

  • Vue3：

    • 基础用法（同 Vue2）：
      html
      <input v-model="username">
      1
    • 本质：:modelValue + @update:modelValue
      html
      <input :modelValue="username" @update:modelValue="username = $event">
      1
    • 新增多 v-model 绑定（组件通信）：
      html
      <UserForm v-model:name="username" v-model:age="userAge"></UserForm>
      1
    • 修饰符用法（同 Vue2，新增 .capitalize 首字母大写）：
      html
      <input v-model.capitalize="username">
      1

二、Vue2 核心进阶（无遗漏） ​

1. 状态管理（Vuex3） ​

（1）核心概念 ​

  • state：全局状态（类似组件的 data）
  • mutations：同步修改 state 的方法（唯一途径）
  • actions：异步操作（可调用 mutations）
  • getters：状态计算属性（类似 computed）
  • modules：拆分模块（解决状态臃肿）

（2）完整示例 ​

js
// src/store/index.js
import Vue from "vue";
import Vuex from "vuex";

Vue.use(Vuex);

// 定义模块
const cartModule = {
  namespaced: true, // 开启命名空间
  state: {
    items: []
  },
  mutations: {
    addItem(state, payload) {
      state.items.push(payload);
    }
  },
  actions: {
    addItemAsync({ commit }, payload) {
      // 模拟异步请求
      setTimeout(() => {
        commit("addItem", payload);
      }, 1000);
    }
  },
  getters: {
    itemCount(state) {
      return state.items.length;
    }
  }
};

export default new Vuex.Store({
  state: {
    count: 0
  },
  mutations: {
    increment(state) {
      state.count++;
    }
  },
  actions: {
    incrementAsync({ commit }) {
      setTimeout(() => commit("increment"), 1000);
    }
  },
  getters: {
    doubleCount(state) {
      return state.count * 2;
    }
  },
  modules: {
    cart: cartModule // 注册模块
  }
});

export default {
  computed: {
    // 映射根状态
    ...mapState(["count"]),
    // 映射根 getters
    ...mapGetters(["doubleCount"]),
    // 映射模块状态（命名空间）

    this.incrementAsync(); // 调用根 action
    this.addItemAsync({ id: 1, name: "商品" }); // 调用模块 action
  }
};

import { ref, computed } from "vue";

export function useCounter(initialValue = 0) {
  const count = ref(initialValue);
  const doubleCount = computed(() => count.value * 2);
  const increment = () => count.value++;
  const decrement = () => count.value--;

  return { count, doubleCount, increment, decrement };
}

四、通用进阶知识（无遗漏） ​

1. 单页应用（SPA）与多页应用（MPA）对比 ​

特性SPA（单页应用）MPA（多页应用）
页面数量1 个 HTML 页面多个 HTML 页面
跳转方式动态切换内容（无刷新）页面整体刷新
首屏加载较慢（需加载所有 JS/CSS）较快（仅加载当前页资源）
路由管理前端路由（vue-router）后端路由
用户体验流畅（无刷新）可能有空白期
SEO较差（需 SSR/SSG 优化）较好
适用场景后台管理系统、社交应用官网、电商首页等对 SEO 要求高的场景

2. SEO 优化方案 ​

  • 服务端渲染（SSR）：Nuxt.js（Vue 生态），服务器返回带数据的完整 HTML
  • 静态站点生成（SSG）：VuePress、VitePress，预渲染为静态 HTML 文件
  • 动态渲染：通过第三方服务（如 Prerender.io）为爬虫返回渲染后的页面
  • 基础优化：语义化标签（<h1>-<h6>、<article>）、合理的 title/meta 标签
