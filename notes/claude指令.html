Claude Code 常用指令速查表 ​

基础操作 ​

指令说明
claude启动交互式会话
claude "你的问题"单次提问模式
claude -p "提示词"以管道模式运行，输出纯文本
claude -c继续上一次对话
claude -r恢复最近一次会话
claude --model <model>指定模型（如 sonnet、opus、haiku）
claude -h查看帮助信息

会话内斜杠命令 ​

命令说明
/help查看帮助
/clear清除当前会话上下文
/compact压缩对话历史，释放上下文窗口
/compact <提示>压缩时保留特定关注的上下文
/cost显示当前会话的 token 用量和费用
/quit 或 /exit退出 Claude Code
/fast切换快速模式（同一模型，输出更快）
/model切换模型
/permissions查看和管理权限设置
/status查看当前状态信息
/memory查看和编辑 CLAUDE.md 记忆文件

MCP (Model Context Protocol) ​

bash
# 添加 MCP 服务器
claude mcp add <name> -- <command>

# 示例：添加文件系统 MCP
claude mcp add filesystem -- npx @anthropic-ai/mcp-filesystem /path/to/dir

# 查看已配置的 MCP 服务器
claude mcp list

# 移除 MCP 服务器
claude mcp remove <name>

Hooks 钩子 ​

在 .claude/settings.json 中配置：

json
{
  "hooks": {
    "PreToolUse": [
      {
        "command": "echo '即将执行工具'",
        "matcher": "Bash"
      }
    ],
    "PostToolUse": [
      {
        "command": "prettier --write $FILEPATH",
        "matcher": "Write|Edit"
      }
    ],
    "Stop": [
      {
        "command": "echo '会话即将结束'"
      }
    ]
  }
}

管道模式 (Piped Mode) ​

bash
# 将文件内容传给 Claude 分析
cat error.log | claude -p "分析这个错误日志"

# 将命令输出传给 Claude
git diff | claude -p "总结这些变更"

# 结合其他工具
find . -name "*.ts" | claude -p "列出所有 TypeScript 文件并分类"

提示词技巧 ​

技巧示例
明确目标"在 src/api 下添加用户注册接口，包含参数验证"
提供上下文"这个项目使用 Next.js 14 + Prisma，帮我..."

指定风格"使用函数式编程风格，避免 class"
约束条件"不要修改现有的接口签名"
